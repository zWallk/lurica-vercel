💡 TIPS IMPORTANTES
────────────────────────────────────────────────────────────────────────────────

1. MySQL DEBE ser accesible desde internet
   └─ Si no, el backend no conectará

2. Variables de entorno en Vercel Dashboard
   └─ NO hacer commit de .env (solo .env.example)

3. CORS configurado dinámicamente
   └─ Funciona con cualquier origen (verificar seguridad)

4. Proxy en Vite (solo desarrollo)
   └─ En producción usa /api/ automáticamente

5. Vercel auto-redeploya en cada push
   └─ GitHub → Vercel (automático)
